### 测试过程中的修复
1. **OPENAI_BASE_URL 支持**: 在 `src/lib/openai.ts` 中添加了 `OPENAI_BASE_URL` env var 支持，允许使用任何 OpenAI 兼容 API（如 DeepSeek, SiliconFlow 等）
2. **OPENAI_MODEL 支持**: 添加了 `OPENAI_MODEL` env var 支持，允许自定义模型名
3. **MOCK_AI 测试模式**: 添加了 `MOCK_AI=true` 环境变量，在无法连接 AI API 时返回模拟摘要，方便本地开发测试
4. **数据库表初始化**: `local.db` 缺少 summaries 表，通过 libsql 直接创建了表结构（schema 来自 `src/lib/db/schema.ts`）

### 已知问题
- OpenAI API (`api.openai.com`) 在当前网络环境被 GFW 屏蔽，无法直连
- `local.db` 不会被 drizzle-kit 自动创建表（kit 配置指向 `data/app.db`，但 API 路由使用 `local.db`）
- 存在两套重复的 DB 实现：
  - `src/lib/db/index.ts` (libsql/Turso, `local.db`) — API 路由使用
  - `src/lib/db.ts` (better-sqlite3, `data/app.db`) — 未被 API 使用
- Schema 也不一致：`db/schema.ts` vs `schema.ts` 列名不同

### 技术债务
- 建议统一两套 DB 实现为一种
- 建议添加 `MOCK_AI` 模式的文档说明
- drizzle.config.ts 和实际 .env.local 的数据库配置不一致
